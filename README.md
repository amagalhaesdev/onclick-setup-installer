# 🚀 OnClick Setup – Automated Windows Installer

> **Projeto de portfólio** — um instalador automatizado para Windows que resolve um problema que eu sempre tive: sempre que resetava o Windows tinha que baixar e instalar tudo manualmente 😫.  
> Este executável automatiza a instalação de software usando o **Windows Package Manager (WinGet)** e um menu interativo.

---

## 📌 SOBRE O PROJETO

Sempre que eu resetava ou formatava meu Windows, eu perdia MUITO tempo baixando e instalando um por um todos os programas que uso no dia a dia.  
Para resolver isso, criei o **OnClick Setup**: um instalador automatizado que detecta o que já está instalado, e instala o resto com apenas alguns cliques.

Este projeto é um **teste técnico e um exemplo para meu portfólio**, demonstrando automação em Windows, scripts em Batch e distribuição de um executável funcional.

## 🧰 REQUISITOS

Antes de rodar o instalador, certifique-se de que:

✔ Está usando **Windows 10 ou 11**  
✔ O **WinGet** está instalado  
✔ Você tem **permissão de Administrador**  
✔ Seu PC está conectado à internet
